## 方法

### 二、接入与预算

| 接口 | 用途 |
|---|---|
| `LightJob::prepare` | 校验格数、依赖数、传播队列和峰值字节预算后分配 |
| `LightJob::poll` | 每次最多处理指定数量的采样格或队列项 |
| `LightJob::finish` | 全部计算完成且输入仍有效时交付目标分区 |
| `LightCache::publish` | 在分区数和字节上限内原子替换缓存 |
| `LightCache::sample` | 返回亮度、不完整标记、待计算或越界 |
| `LightCache::validate_stamp` | 检查使用光照结果的后续工作是否仍有效 |

每次poll另有一次受依赖数上限约束的输入检查，每个队列项最多检查6个邻格。预算耗尽返回错误，部分计算不会进入缓存。丢弃LightJob即可取消，不修改权威地形。

缓存绑定世界、会话、内容摘要、分区修订和可读状态。地形编辑、邻区装卸、加载完成或内容变化都会使旧结果失效；不同缓存实例的凭据不能混用。调用者在发布依赖光照的工作前再次验证LightStamp。

LightLimits.bytes包含任务结构、预分配格缓冲、依赖、队列和完成时的输出峰值，不含分配器管理开销。缓存统计包含LightSection结构及其缓冲，映射节点通过分区数上限约束。memory_resident把缓存列入Mesh类，存在消费者时Pinned，无消费者时UnsubscribedDerived，由宿主显式释放。

## 结果

### 一、计算规则

`torse_world_services::lighting`提供可分步执行的单通道发光传播。亮度取0至15，发光强度乘15后四舍五入；进入一格时扣除该格吸收率乘15的向上取整值，最低扣1。吸收与渲染形状、材质透明模式独立。

每个目标分区采集周围15格范围，按世界高度裁剪。亮度最多15且每步至少减少1，范围外的光源无法影响目标。缺失邻区按不透光处理，结果标记`complete=false`，调用者可以等待依赖装入后重算。

### 三、回归结果

执行：

```sh
cargo test -p torse-world-services --test lighting --locked
cargo test --workspace --all-targets --locked
```

新增8项光照测试。随机16立方格场景与独立的15轮同步松弛计算逐格一致，小批和大批poll结果相同。跨分区光源强度15，边界相邻格14，距离14格为1，距离15格为0；0.5吸收率滤光格扣8。

验证覆盖正负坐标边界、阻光、光源移除、邻区卸载及装回、加载完成但修订不变、过期任务、内容和会话切换、缓存实例隔离、容量拒绝保留旧缓存、内存分类及坐标溢出。

全工作区698项测试通过，零忽略；格式、Clippy、Rustdoc和mods编译通过。光照为可重算数据，不写入快照、日志或网络载荷，不改变格式版本。本轮提供内核单通道发光服务，天空光、彩色光和前端着色接入不在本次范围。
