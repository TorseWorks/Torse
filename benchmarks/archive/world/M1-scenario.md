## 目标

场景内含断言，任一验收项回退即以非零状态退出。

本机未安装工作区锁定的1.93.1工具链，且`static.rust-lang.org`不可达，因此用已安装的1.94.0执行；代码未使用1.94.0特有的语言特性。

## 方法

### 场景内容

使用M0夹具内容（石头、玻璃半砖、植物）建立32边长分区。生成`x`从-3到3、`z`从-1到1共21个分区，地面为`y < 1`的石头。在`x = 20`处放置4格高、11格宽的墙，并在`z = 2`处铺一排玻璃半砖。玩家碰撞体为0.6x1.8x0.6的AABB。

依次验证：

1. 向墙行走240步，每步施加`+0.25`的水平位移与`-0.1`的重力。
2. 反向行走160步，跨过`x = 0`的分区边界。
3. 对零号分区建网格，编辑其中一个方块后用旧修订戳写入缓存。
4. 查询并尝试写入未装载分区。
5. 释放全部票据并卸载所有分区。

## 结果

### 输出

```text
sections_loaded=21
dense_cells=688128
blocks_edited=49
steps=400
blocked_steps=164
final_x=19.700
seam_x=-20.300
mesh_faces=2116
stale_rejected=1
cache_bytes=258640
unloaded_blocked=true
unloaded_edit_refused=true
```

### 判读

- `final_x = 19.700`：墙面在`x = 20`，碰撞体半宽0.3，玩家停在墙面外侧，未穿墙。
- `seam_x = -20.300`：反向行走跨过`x = 0`的分区边界，说明负坐标分区与邻区装配正确。
- `blocked_steps = 164`：到达墙后剩余步数均被阻挡，符合预期，不代表卡死。
- `mesh_faces = 2116`：地面顶面1024面，底面1024面（下方分区未装载，保守保留），加上分区边界面与墙体、半砖表面。未装载的邻区不剔除面，避免接缝处出现空洞。
- `stale_rejected = 1`：编辑后分区修订变化，旧网格任务被缓存拒绝，满足“旧网格不得覆盖新状态”。
- `unloaded_blocked`与`unloaded_edit_refused`：未装载区域既不返回空气，也不接受写入。
