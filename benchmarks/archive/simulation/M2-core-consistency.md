## 目标

## 方法

### 实现行为

持久世界快照与日志变更现在按组件持久策略筛选数据。Always保留，Never省略，OwnerDefined默认保留，所有者可在可信启动阶段选择省略。生命周期观察采用相同投影，包括检查点之后重放的销毁记录。无损交换与授权复制保持各自语义。持久投影为空时仍记录提交位置和执行结果。

声明component_defaults的方块获得一个固定位置的附属实体，内核随单元事务自动创建、保留、替换或移除它。所有者通过ComponentSchemas::set_block_default登记经过校验的初始字段，必填字段不会自动推断。保留模式core:schema/block_instance保存稳定方块键和整数格坐标。普通编辑、显式生命周期请求及移动不能改变该绑定；普通组件编辑仍须声明的所有者授权。

自动生成按规范格坐标顺序排在显式生成之后，共用身份分配器、生命周期预算、日志预留和原子复制批次。恢复依据单元写入验证自动生命周期，不调用模块代码。快照捕获和恢复完成时拒绝缺失、孤立、重复或位置偏移的绑定。附属实例不会额外获得行走体碰撞盒或客户端实体占位几何。

放置占用检查现在解析目标方块状态的实际碰撞形状，覆盖上半、下半以及半高形体补全后的完整形状。

## 结果

### 验证结果

Windows工作区验证通过606项测试，无忽略项。格式检查、禁止警告的Clippy及Rustdoc检查通过。新增覆盖横跨内容编译、模拟、持久执行和客户端几何；客户端测试直接比较生成的几何，不需要GPU。

| 场景 | 实际结果 |
|---|---|
| 行走体旁的上半、下半状态放置 | 仅实际占用的半区拒绝放置；补全为完整形状时拒绝重叠 |
| 放弃预备结果或缺少初始字段 | 不消耗单元、实体、序号或分配身份 |
| 状态变化、替换及破坏 | 同方块保留身份；替换分配新身份；破坏移除实例 |
| 同一事务内显式及自动生命周期 | 共用一个身份区间和生命周期记录；重放验证拒绝伪造初始数据 |
| 自动生命周期超过256个目标 | 发布前拒绝 |
| 跨模块编辑与绑定伪造 | 接受所有者编辑；拒绝销毁与编辑交叠、绑定编辑或移动 |
| 检查点后更新组件再销毁 | 恢复持久组件及分配水位，运行态组件不恢复；旧完整记录也能重放 |
| 世界投影为空的纯运行态任务 | 成功重放已提交结果及序号 |
| 公开运行态组件与私有持久组件 | 运行期间仍复制公开组件；私有持久字段保持隐藏 |
| 子进程在交互工作冻结后退出 | 重启后仅执行一次冻结放置，在已有身份1之后创建身份2 |
| 子进程在放置持久确认后退出 | 重启后重放同一身份2，不重复执行放置 |
| 客户端收到附属实例 | 地形及普通实体占位几何保持不变 |

进程测试使用退出码74和75，重开实际日志和检查点目录，子进程不执行正常关闭流程。覆盖范围为进程终止，未验证硬件断电。

## 边界

冻结任务独立于附属世界状态保存操作意图与精确前置条件。未完成任务若依赖纯运行态组件，重启后可能因该组件缺失而被拒绝；所有者须重新初始化临时状态并安排后续工作。已完成任务重放时不调用回调。

须在装配WorldAuthority前解析OwnerDefined并登记初始字段。宿主须将这些启动选择纳入规则兼容版本，恢复时使用相同配置。直接安装Section时，须为声明附属实例的方块提供匹配实体；捕获和恢复拒绝不配对的单元，不会静默分配历史身份。

未新增线格式字段：WorldCodec保持布局3，Execution提交保持版本2。未声明附属实例的既有世界保持原生命周期行为；已有声明却未配对的单元需要显式迁移。

本次未实现物品扣除、掉落、关联容器创建、缺失模块保留、通用实体碰撞体及持久分区流送。其他普通实体仍沿用当前行走体占用假设，动作规划至提交之间仍没有独立空间见证。本报告不作性能结论。
